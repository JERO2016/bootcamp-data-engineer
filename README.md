# Bootcamp Data Engineer Jr.

Repositorio de aprendizaje autodidacta orientado a la preparación para 
roles de Data Engineer Jr. y HRIS Analyst con stack de datos moderno.

## Stack técnico

- **Lenguaje:** Python 3.11
- **Bases de datos:** PostgreSQL, AlloyDB
- **APIs:** FastAPI, SQLAlchemy
- **Contenedores:** Docker, Docker Compose
- **Orquestación:** Apache Airflow
- **Herramientas:** Git, GitHub, VSCode, JupyterLab, DBeaver

## Sobre este repositorio

Cada lección incluye ejemplos prácticos y un ejercicio aplicado al 
dominio de nómina y recursos humanos — área donde tengo más de 13 años 
de experiencia operativa con Oracle HRMS R12.

El objetivo es combinar conocimiento de dominio profundo con ingeniería 
de datos aplicada, construyendo un portfolio técnico sólido y verificable.
